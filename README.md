## Selected engineering work

### Semantic LiDAR–Camera Fusion with SAM3

A ROS 2 perception pipeline that associates image segmentation masks with LiDAR points to support semantic understanding of 3D scenes.

- Projecting LiDAR geometry into camera coordinates
- Associating segmentation masks with 3D points
- Producing semantically labeled point clouds
- Applying point-cloud filtering and clustering
- Publishing object detections and perception outputs in ROS 2

**Stack:** C++ · ROS 2 Jazzy · OpenCV · PCL · SAM3

### LiDAR Motor Calibration with ICP

Calibration work for a rotating LiDAR sensor using registration of consecutive point-cloud sweeps.

- Registering point clouds using Iterative Closest Point
- Estimating angular alignment and timing offsets
- Measuring motor speed across sweep directions
- Averaging directional measurements to improve stability

**Stack:** C++ · ROS 2 · PCL · ICP
